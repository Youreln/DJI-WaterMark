# DJI WaterMark｜大疆全系水印下载中心

✅ 已上线 GitHub Pages  
🌐 访问地址：https://youreln.github.io/DJI-WaterMark

包含 61 个机型、493 个透明 PNG 水印文件，支持预览、筛选、双视图切换、一键下载。

---

## 功能特性
- 完整收录：61 机型 / 493 个透明 PNG 水印
- 分类清晰：无人机系列 + 手持设备 Osmo 系列
- 双视图切换：卡片模式 + 文件目录树模式
- 水印预览：每个文件支持小图预览
- 多条件筛选：搜索、语言、焦段、尺寸
- 大疆风格 UI：深色毛玻璃 + 模糊动画
- 一键下载：点击直接保存透明 PNG
- 支持 GitHub Pages 直接部署

## 使用方法

### 1. 打开网站
进入上方链接即可使用全部功能。

### 2. 视图切换
- 卡片模式：预览水印、筛选、快速下载
- 目录模式：浏览完整文件结构

### 3. 搜索与筛选
- 搜索：输入机型名称快速查找
- 语言：简体中文、English、日本语、한국어
- 焦段：24mm / 70mm / 166mm 等
- 尺寸：24px / 48px / 56px / 72px 等

### 4. 下载水印
点击水印按钮 → 自动下载透明 PNG 文件。
